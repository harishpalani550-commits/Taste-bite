TASTEBITE – ONLINE FOOD ORDERING WEBSITE

Files included:
- index.html : Website structure
- style.css  : Styling, responsive layout, and animations
- script.js  : Menu, search, category filters, cart, and demo checkout

HOW TO RUN
1. Extract the ZIP file.
2. Open the Tastebite-Online-Food-Ordering folder.
3. Double-click index.html or open it in Chrome/Edge/Firefox.
4. Internet connection is recommended for Google Fonts and food photos.

NOTE
This is a front-end demo project. Orders are simulated; it does not take payments or send real deliveries. Cart items are stored in your browser's local storage.
